## Обрезка

Порог предупреждения: 5.0%. Фактически обрезано (train): 1.0% — в норме.

p99 длины в токенах — 3376 при `max_seq_len` 3456; хвост длиной до 6075 может терять конец ответа. Примеров, у которых обрезка съела ответ целиком: 0 (такие выброшены).

Длины и доля обрезки посчитаны до фильтрации, по всем входным примерам.

- train: вход 1388, сохранено 1388, без ответа отброшено 0; обрезка 1.01%; потеряно токенов ответа 14678.
- val: вход 154, сохранено 154, без ответа отброшено 0; обрезка 0.65%; потеряно токенов ответа 1459.

## Граница маски и BPE

Запасной путь по символьным офсетам сработал на 0 примерах train. Основной путь (токены промпта совпадают с началом токенов полного текста) держится, потому что шаблон Qwen3 заканчивает промпт переводом строки — BPE не склеивает его с началом ответа. У шаблона, который обрывается посреди слова, склейка будет, и тогда границу задаёт первый токен, начинающийся не раньше конца промпта.
