## Как устроено

`src/prompt.py` — единый шаблон обучения и инференса. Стадия проверяет
побайтовый префикс, токенизирует без повторного добавления спецтокенов,
определяет границу ответа по токенам либо offsets и ставит −100 на промпте.
`src/collate.py` динамически паддит слева: attention_mask нулевая, labels −100.
В `data/tokenized/{train,val}.pt` лежат списки input_ids / attention_mask / labels;
батч тензоров собирается коллатором позже, при обучении.

`enable_thinking: false` исключает пустой блок рассуждений из лосса.
Packing отключён: без блочно-диагональной attention mask он смешивает
контекст независимых диалогов. При попытке включить его стадия останавливается.
`src/pack.py` оставлен как неиспользуемая утилита исходной заготовки.

## Восстановление после клонирования

Git содержит код, отчёты, метрики и DVC-указатели, **но не сами данные/тензоры**.
На этом Mac DVC remote находится в `../dvc_remote` относительно проекта
(запись `../../dvc_remote` в .dvc/config отсчитывается от .dvc/).
Это локальное хранилище, не доступное через GitHub. Для другой машины надо
передать его отдельно или взять точный снимок из ДЗ 3.

С доступным DVC remote:

```bash
make install
uv run dvc pull
make check
```

Если рядом находится папка ДЗ 3 с исходными данными:

```bash
make install
make import-data
make tokenize
make check
```

Для другого расположения: `uv run python -m scripts.import_hw3 --source-dir /путь/к/дз3/data`.
Импорт сверяет SHA256 всех файлов и не перезаписывает отличающийся снимок.
Входы ДЗ 4 скопированы без изменений. Первый запуск токенизатора после клонирования
требует интернет; если он уже в HF-кеше, можно использовать `HF_HUB_OFFLINE=1 make check`.
`make sample` оставлен только для преподавателя и здесь не используется.
